# 测试页面命名、清点与删除要求

2026-10-29 用户要求：停止擅自添加测试题头；找出历次测试页面，并将清理这些页面作为每次导入清单的必做项。旧约定“所有测试页保持 WTJTreeTesting 前缀”废止。

## 标题与交付

- 创建页面前列出精确标题、命名空间、内容模型、用途、预期链接及创建/更新操作。沿用用户确定的正式标题；不能自行加 Testing、Demo、日期、随机后缀，也不能为了去掉测试前缀而另行猜测正式标题。
- 离线试验放在本地预览；只有用户明确要求线上隔离测试时才建立测试标题，并同时登记完整依赖与退休条件。模板、模块、数据、脚本、文件和人工内容子页必须分开登记，不能只列入口文章。
- 标题变更必须检查文章链接、模板调用、Lua require/loadJsonData、ResourceLoader、JS/CSS 与文件引用；提供旧→新标题映射，替代包验收后删除旧测试标题。不能只改入口标题，或依赖重定向长期掩盖错误命名。
- vehicle_page.py 现在默认使用 WTJ 共用资源和载具代码文章标题；vehicle_pack.py 生成正式标题的导入包、旧→新映射与清理清单。vehicle_demo_pack.py 命令行转到正式打包器。build.py 的旧科技树试验 XML 仅作离线回归，不得作为正式交付。当前三辆载具的本地标题迁移已验证；线上导入、玩家子页迁移和旧页删除仍需管理员执行并核对。

## 每次生成导入列表的必做项

1. 调用 `testing_cleanup.write_cleanup` 同步刷新清理清单；每个交付说明必须给出 CLEANUP.md 和 CLEANUP.html 的位置。不得复用固定“37 页”等过时数字。生成的站点材料保留在被忽略的 wiki/ 或 work/，不提交公开仓库。
2. 汇总现存及历史 XML、manifest、导入截图、既往登记和只读站点查询；对同名页去重并保留全部来源。当前注册表保留历史候选，不能因本地旧包被清空就遗忘旧标题。
3. 分开记录本地曾生成、截图确认曾导入、线上当前存在/缺失/未知和查询时间。截图中同一模块重复显示不重复计数。查询失败、导出缺页都不能作为已删除证明。
4. 导入清单同时列出：新增/更新、仍在使用的测试页、待退休测试页、人工子页迁移、文件用途审查及删除验收。清理是本次部署必做步骤，不能省略，也不能在仅生成清单时声称已执行删除。
5. 先从站点导出当前修订备份，再导入并验收替代标题及其依赖，随后删除退休测试页。没有替代但用户决定退休的孤立演示可整体清理。当前包仍创建/依赖的标题标为 hold-current-import，阻止将其同时当成退休页处理；必须在替代包中解决，不能静默永久保留。
6. 删除后查存在性及删除日志，记录成功、原已不存在、失败、仍有依赖、待迁移；失败项和未完成项带入下次清单。未完成删除核对时不能报告部署清理完成。

## 管理员删除方式与边界

MediaWiki 的 Special:Import 只负责导入修订，不能用导入 XML 删除页面。导入空内容、添加 delete 字段或建立重定向都不是实际删除。

`CLEANUP.html` 为每个精确标题提供查看、链入和 `action=delete` 管理员入口，可按标题/处理要求筛选。少量页面可以直接使用。大量页面可以由管理员在检查清单后通过本站 `action=delete` API 顺序删除，或使用本站确实安装并适用的批量删除工具；不假设 BWiki 已安装 DeleteBatch/Nuke，不提供未经核实的特殊页面作为可用能力。API 删除须使用登录会话、CSRF token、明确白名单与原因，逐项记录结果，禁止按模糊前缀自动删所有匹配页。当前生成器只生成清单和入口，不登录、不执行写入 API。

人工 `/basic-info`、`/player-content`、`/user-content` 子页先备份迁移，不能因测试父标题退役而丢掉玩家内容。个人 common.js 仅移除测试 loader，不删除整页。文件需要额外保存二进制、检查文件用途和跨批次共享；模块/模板需检查链入。依赖先退出使用，再删除支持页，图片最后处理。

正式 WTJ 模块/模板/数据/脚本、正式科技树、Tr 及数据库、ResourceLoader、Common.js、Item/Specs 背景和复用图标不在测试删除集合。已移动到正式名的资源按新名保留。旧 SMW 页、未知命名及仅在个人贡献/导入/移动日志中存在的页属于待补查范围，不能声称已穷尽。

## 本地使用

```text
python scripts/testing_cleanup.py
python scripts/testing_cleanup.py --refresh-site
```

默认输出 `work/reports/testing-cleanup/`：完整 CSV、带来源的 JSON、供 Special:Export 使用的纯标题列表、待退休候选列表、处理说明和管理员入口。`--refresh-site` 只读枚举已知四个测试系列在主/文件/MediaWiki/模板/模块命名空间的页面，再查询精确标题（包括登记的个人脚本）；失败会明确记录为未完成。候选列表不是已核实安全的自动删除白名单。
